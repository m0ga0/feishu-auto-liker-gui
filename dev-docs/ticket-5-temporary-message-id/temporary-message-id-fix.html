Ticket 5: Handle Temporary Message IDs

Review and comment on the implementation

BUG Issue Description

Messages processed twice - once with temporary ID (10-char alphanumeric) and once with real ID (19-digit numeric).

Example:

[TrCbtDNOPi]:出明天 -> True      # Temporary ID processed
[7643842845769469666]:出明天 -> True  # Same message processed again!
REFACTOR 1 Simplified Regex Pattern

src/parkbot/core/bot.py

Old (Nested If Clauses)

def is_temporary_message_id(message_id):
    if not message_id:
        return True

    # Nested if clauses - not clean
    if len(message_id) == 10 and re.match(r'^[a-zA-Z0-9]+$', message_id):
        if re.search(r'[a-zA-Z]', message_id):
            return True

    return False

New (Single Regex)

@staticmethod
def is_temporary_message_id(message_id):
    if not message_id:
        return True

    # Single regex with lookahead
    return bool(re.match(
        r'^(?=.*[a-zA-Z])[a-zA-Z0-9]{10}$', 
        message_id))

Improvements:

  • Single regex pattern instead of nested if clauses
  • Uses positive lookahead (?=.*[a-zA-Z])
  • Cleaner, more maintainable code
REFACTOR 2 Object-Oriented Design

src/parkbot/core/bot.py

Old (Global Function)

# Global scope - NOT object-oriented
def is_temporary_message_id(message_id):
    ...

class RPABotCore:
    ...
    if is_temporary_message_id(msg_id):
        ...

New (Static Method)

class RPABotCore:
    ...
    @staticmethod
    def is_temporary_message_id(message_id):
        ...

    if self.is_temporary_message_id(msg_id):
        ...

Benefits:

  • Better encapsulation: function belongs to the class
  • No global namespace pollution
  • Object-oriented design principles
  • Easier testing
