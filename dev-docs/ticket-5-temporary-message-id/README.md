# Ticket 5: Handle Temporary Message IDs in Feishu Chat

**Branch**: `fix/message-db`  
**Date**: 2026-05-25  
**Status**: ✅ Completed

---

## Problem Description

When new messages arrive in the Feishu group chat, the HTML DOM creates and inserts new message elements. During this process:

1. The message element is first inserted with a **temporary ID** (10-character alphanumeric string like `TrCbtDNOPi`, `mlD0HVHwxI`, `3y6IegQHQH`)
2. As the element finishes rendering and actual message metadata is retrieved, the ID changes to the **real format** (19-digit numeric string like `7643842788513042144`)
3. If the bot retrieves the message during this transition window, it processes the same message twice - once with the temp ID and once with the real ID

### Log Evidence

```
[TrCbtDNOPi]:。。。 -> False           # Temporary ID - processed
Saved 1 message states
[7643842788513042144]:。。。 -> False   # Real ID - same message processed again!
Saved 1 message states
[mlD0HVHwxI]:出明天 -> True             # Temporary ID
Reacting to 1 matched messages...
Saved 1 message states
[7643842845769469666]:出明天 -> True    # Real ID - duplicate reaction!
Reacting to 1 matched messages...
Saved 1 message states
```

## Root Cause

The `_get_messages()` method in `bot.py` extracts message IDs from DOM elements immediately when found, without validating whether the ID is in the correct format. Temporary IDs are assigned by Feishu's frontend before the full message metadata is loaded.

## Solution

Add ID format validation to skip messages with temporary IDs. They will be re-fetched on the next check cycle when they have proper IDs.

### ID Format Characteristics

| Type | Format | Example | Length | Pattern |
|------|--------|---------|--------|---------|
| Temporary | Alphanumeric (contains letters) | `TrCbtDNOPi` | 10 chars | `(?=.*[a-zA-Z])[a-zA-Z0-9]{10}` |
| Real | Numeric only | `7643842788513042144` | 19 chars | `[0-9]{19}` |

## Implementation

### Refactoring 1: Simplified Regex Pattern

**Original Implementation (Nested If Clauses):**
```python
def is_temporary_message_id(message_id: str) -> bool:
    if not message_id:
        return True

    # Nested if clauses - not clean
    if len(message_id) == 10 and re.match(r'^[a-zA-Z0-9]+$', message_id):
        if re.search(r'[a-zA-Z]', message_id):
            return True

    return False
```

**Refactored Implementation (Single Regex with Lookahead):**
```python
@staticmethod
def is_temporary_message_id(message_id: str) -> bool:
    """Check if a message ID is a temporary ID from an unrendered DOM element.

    Temporary IDs are generated by Feishu before the message metadata is fully
    loaded. They appear as 10-character alphanumeric strings (e.g., 'TrCbtDNOPi').
    Real message IDs are 19-digit numeric strings (e.g., '7643842788513042144').
    """
    if not message_id:
        return True

    # Single regex with lookahead:
    # - (?=.*[a-zA-Z]) : positive lookahead, must contain at least one letter
    # - [a-zA-Z0-9]{10} : exactly 10 alphanumeric characters
    return bool(re.match(r'^(?=.*[a-zA-Z])[a-zA-Z0-9]{10}$', message_id))
```

**Improvements:**
- Single regex pattern instead of nested if clauses
- Uses positive lookahead `(?=.*[a-zA-Z])` to check for letter presence
- Cleaner, more maintainable code
- Better performance (single regex match vs multiple checks)

### Refactoring 2: Object-Oriented Design

**Original (Global Function - Anti-pattern):**
```python
# Global scope - NOT object-oriented
def is_temporary_message_id(message_id: str) -> bool:
    ...

class RPABotCore:
    ...
    if is_temporary_message_id(msg_id):  # Global call
        ...
```

**Refactored (Static Method - Proper OOP):**
```python
class RPABotCore:
    ...
    @staticmethod
    def is_temporary_message_id(message_id: str) -> bool:
        """Check if a message ID is temporary..."""
        ...

    async def _get_messages(self, group_name: str = "") -> list[dict]:
        ...
        if self.is_temporary_message_id(msg_id):  # Method call
            self.log(f"⏳ 跳过临时消息 ID: {msg_id}")
            continue
```

**Benefits:**
- Better encapsulation: function belongs to the class that uses it
- No pollution of global namespace
- Object-oriented design: related functionality grouped together
- Easier testing: access via `RPABotCore.is_temporary_message_id()`
- Clearer intent: shows this is a utility method of the bot class

## Testing

**File**: `tests/core/test_message_id_validation.py`

```python
from parkbot.core.bot import RPABotCore

class TestIsTemporaryMessageId:
    """Tests for is_temporary_message_id static method."""

    def test_temporary_id_10_chars_with_letters(self):
        """Temporary IDs are 10 chars with letters."""
        assert RPABotCore.is_temporary_message_id("TrCbtDNOPi") is True
        assert RPABotCore.is_temporary_message_id("mlD0HVHwxI") is True
        assert RPABotCore.is_temporary_message_id("3y6IegQHQH") is True

    def test_real_id_19_digits(self):
        """Real message IDs are 19 digits."""
        assert RPABotCore.is_temporary_message_id("7643842788513042144") is False
        assert RPABotCore.is_temporary_message_id("7643842845769469666") is False
        assert RPABotCore.is_temporary_message_id("7643843154713546464") is False

    def test_empty_string(self):
        """Empty string should be treated as temporary (invalid)."""
        assert RPABotCore.is_temporary_message_id("") is True

    def test_none_value(self):
        """None should be handled gracefully."""
        assert RPABotCore.is_temporary_message_id(None) is True

    def test_mixed_alphanumeric_19_chars(self):
        """19-char mixed alphanumeric is not temporary (unusual but possible)."""
        assert RPABotCore.is_temporary_message_id("7643842788513042144A") is False

    def test_10_digit_only(self):
        """10 digits only might be a shortened ID, not temporary format."""
        # 10 digits without letters is ambiguous - could be timestamp
        # We only flag as temporary if it has letters (which real IDs never do)
        assert RPABotCore.is_temporary_message_id("1234567890") is False

    def test_various_lengths(self):
        """Various length strings."""
        # Too short
        assert RPABotCore.is_temporary_message_id("abc") is False
        # Too long with letters
        assert RPABotCore.is_temporary_message_id("abcdefghijklmnopqrs") is False
        # Exactly 10 digits only
        assert RPABotCore.is_temporary_message_id("0123456789") is False
```

## Impact

- **Before**: Messages processed twice (once with temp ID, once with real ID), leading to:
  - Duplicate database entries
  - Wasted processing cycles
  - Potential duplicate reactions
  - Confusing log output

- **After**:
  - Temporary ID messages are skipped with a log message
  - They will be picked up on the next check cycle with their real IDs
  - No duplicate processing
  - Cleaner logs
  - Better code quality (OOP design, clean regex)
