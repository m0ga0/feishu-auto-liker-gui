Option B: Gradual Migration - ElementHandle to Locator

This proposal uses Playwright's modern Locator API for read-only message retrieval while keeping ElementHandle for complex JavaScript interactions (reaction buttons).

Strategy: Use Locator for _get_messages() (read-only, auto-waiting) but keep ElementHandle for _react() (complex JS evaluation for finding reaction buttons).

156async def _get_messages(self, group_name: str = "") -> list[dict]:
157    messages = []
158    max_msgs = self.monitor_settings.max_messages_per_check
159
160    try:
161        # Use Locator API for better auto-waiting and retry
162        wrapper_locator = self._page.locator(SELECTORS["message_wrapper"])
163        count = await wrapper_locator.count()
164        if count == 0:
165            return messages
166
167        # Iterate using nth() which returns Locator

169            try:
