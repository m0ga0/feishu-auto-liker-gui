Fix Plan: target_pattern Should Store Actual Pattern String

Review and comment on the fix plan before implementation

BUG Issue Description

Current Behavior: The target_pattern column contains hardcoded strings "matched" or "checked" instead of the actual regex pattern that was used.

Expected Behavior: Store the actual pattern string (e.g., "re:.*(出|整出).*(车位|停车位).*") that was checked or matched against the message text.

Why This Happened: PatternMatcher.matches() only returns True/False, not which pattern matched. The code was written with placeholder strings that were never replaced.

STEP 1 Add Method to PatternMatcher

src/parkbot/core/matcher.py

def get_matching_pattern(self, text: str) -> Optional[str]:
    """Return the first pattern that matches the text, or None if no match."""
    for compiled_pattern in self._compiled:
        if compiled_pattern.search(text):
            return compiled_pattern.pattern  # Return the original pattern string
    return None
STEP 2 Update Message Processing

src/parkbot/core/bot.py (Lines 410-421)

Old Code

for msg_data in messages:
    msg_id = msg_data["id"]
    msg_text = msg_data["text"]

    # Only returns True/False
    is_match = self.matcher.matches(msg_text)

    if is_match:
        self.match_count += 1
        # No pattern info stored!
        matched_messages.append(msg_data)
    else:
        no_match_messages.append(msg_data)

New Code

for msg_data in messages:
    msg_id = msg_data["id"]
    msg_text = msg_data["text"]

    # Get actual pattern that matched
    matched_pattern = self.matcher.get_matching_pattern(msg_text)
    is_match = matched_pattern is not None

    if is_match:
        self.match_count += 1
        # Store the actual pattern
        msg_data["matched_pattern"] = matched_pattern
        matched_messages.append(msg_data)
    else:
        no_match_messages.append(msg_data)
